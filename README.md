# 🛒 Dự án Thương Mại Điện Tử (E-Commerce Web Application)

## 📝 Giới thiệu
Dự án **Thương Mại Điện Tử** là một nền tảng mua sắm trực tuyến cung cấp trải nghiệm tuyệt vời cho người dùng trong việc tìm kiếm, xem chi tiết và mua sắm các sản phẩm. Hệ thống bao gồm cả giao diện cho người dùng cuối (Customer) và trang quản trị (Admin Dashboard) để quản lý sản phẩm, đơn hàng và người dùng.

## ✨ Tính năng nổi bật
### Dành cho Khách hàng (Users):
- 🔐 Đăng ký / Đăng nhập (Authentication & Authorization).
- 🔍 Tìm kiếm và lọc sản phẩm theo danh mục, giá cả.
- 🛒 Thêm, sửa, xóa sản phẩm trong Giỏ hàng (Cart).
- 💳 Thanh toán đơn hàng (Checkout) và theo dõi trạng thái.
- ⭐️ Đánh giá và bình luận sản phẩm.

### Dành cho Quản trị viên (Admin):
- 📊 Bảng điều khiển thống kê doanh thu, đơn hàng.
- 📦 Quản lý Sản phẩm (Thêm, Sửa, Xóa).
- 📂 Quản lý Danh mục sản phẩm.
- 👥 Quản lý Người dùng và phân quyền.
- 🧾 Quản lý Đơn hàng và cập nhật trạng thái giao hàng.

## 🛠 Công nghệ sử dụng (Stack)
*(Vui lòng điều chỉnh lại cho đúng với công nghệ bạn sử dụng)*
- **Frontend:** React.js / Vue.js / HTML, CSS, JavaScript
- **Backend:** Node.js (Express) / PHP (Laravel) / Java (Spring Boot)
- **Database:** MongoDB / MySQL / PostgreSQL
- **Khác:** Redux/Zustand, JWT (JSON Web Token)...
